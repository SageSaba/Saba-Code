## 2026-07-21 — Monday
*(Voice Chat Briefing.md and the Family Gate design also landed as commits this day, from a separate session not narrated here.)*

- **The AI-drives-the-archive road tried tonight, and blocked.** Saba is on Open WebUI (Docker, localhost:3000) with Ollama already running. Goal: get an AI chat to call the Archive AI Connector (port 8766) as a tool, so it answers from real evidence instead of guessing.
- Wired the connector in as a Tool Server (Settings → Integrations). Key gotcha found: Open WebUI calls tool servers **from the browser**, not the Docker backend — so the URL has to be `localhost:8766`, not `host.docker.internal:8766` (that only resolves inside the container). Connector confirmed reachable and correct once that was fixed.
- **All three local Ollama models failed, three different ways:** qwen3:4b hallucinated a fake tool (`search_calendar_events`) that doesn't exist in the connector at all; gemma4:12b did the same and then ran away into a 90+-call loop inventing a fictional "Project Alpha" business scenario; llama3.1:8b printed a raw malformed JSON function-call as plain chat text instead of actually calling anything. None of them ever sent a single real request to the connector.
- **Tried a hosted model next: Google Gemini**, using Saba's own AI Studio key, added as an OpenAI-compatible connection. Settled on `gemini-3.5-flash` after `gemini-2.5-flash` turned out deprecated for new keys. With the archive tool switched off, it chats perfectly. With the tool switched on: **empty answer, every time** — five attempts, same result, confirmed repeatable. The connector's own logs show it was never actually queried; only its spec was fetched.
- **Where it stands:** four different models, four different failure modes, zero successful AI-driven archive queries through Open WebUI. The connector itself and the Gemini connection are each independently confirmed working — the break is specifically in how Open WebUI hands Gemini the tool definitions. Not yet diagnosed further. Saba's word tonight: retiring; the plan to make this work "is not going that way." The reliable path meanwhile stays what it's always been — asking the connector directly (curl, or the Ask the Archive page).
